# Think, Visualize, Find the Right AI, Execute

September 30, 2026 · AK

1. Start with the problem that you want to solve.
2. Visualize it and think about what you want the final output to be.
3. Find a tool to solve that.

Go in this order:

## 1. THINK
What do I want to create, solve, or achieve?

## 2. VISUALIZE
Make the idea clear in your head. What should the final result look like?

## 3. FIND THE RIGHT TOOL
Don't obsess over one AI tool. Find the tool that solves that specific problem.

## 4. EXECUTE
Use AI to reduce the friction and actually make it.

## 5. REPEAT
The skill is not knowing 100 AI tools. It's knowing what to build + which tool to use + actually doing it.


One line I'd keep:
> Think → Visualize → Find the right AI → Execute → Repeat.
